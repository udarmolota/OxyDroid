Quick start

OxyDroid is a launcher: it runs your own copy of Oxygen Not Included on Android. The game itself is not included.

  1. To run it you need your own copy of the game, for example bought on Steam (or on GOG). OxyDroid runs the Linux version of the game, natively: Unity's own Android player draws it with Vulkan, and the game's code runs on an ARM64 Mono.
  2. Get the game into the app. With Steam, tap Game on the bottom bar, sign in and download: the instance is created by itself. For the other ways, see Getting the game.
  3. An instance is one installed copy of the game. Each one has its own card on the main screen and its own settings behind the gear icon.
  4. Tap ▶ on the card. The first launch of an instance takes longer while the game prepares its files (on some phones its textures are also converted once, see Picture and frame rate).

You need Android 11 or newer, a 64-bit phone with Vulkan and about 8 GB of free storage for the first setup (an installed instance then takes about 3.5 GB). Minimum: Snapdragon 865 / Dimensity 1000–1100 class. Recommended: Snapdragon 8 Gen 1 / Dimensity 8100 or newer. Weaker phones may start the game, but they are not a target.

The ? at the top of a screen opens this page at the part about that screen.

Something went wrong? See Reporting a problem.

Getting the game

OxyDroid needs the Linux version of Oxygen Not Included, of the current game version. An older version, the Windows version or a repack will not run. Pick one of the ways below.

1. From Steam, in the app

  1. Tap Game on the bottom bar, tab Game.
  2. Sign in with your Steam account. The sign-in is approved in the Steam Mobile app, so Steam Guard must be on there; Steam Guard codes are not supported. Your login goes to Steam only and is never stored.
  3. Tap Download. The instance is created by itself, with the Linux build, the one file it needs from the macOS build (SimDLL) and the DLCs your account owns.
  4. After the download a backup copy of the game is packed into Download/OxyDroid (this needs All files access). It takes a few minutes after the bar reaches 100%: keep the app open. From that ZIP you can make more instances later without downloading again.
  5. If the download stops, start it again with the same instance name: it continues where it stopped.

2. From GOG

  1. Side menu → Download from GOG.
  2. Sign in on GOG's own page. OxyDroid never sees your password.
  3. The app looks for Oxygen Not Included in your GOG library and offers its Linux installer. It is saved into Download/OxyDroid.
  4. Tap Create an instance: the game is taken straight out of the installer.

If GOG has no macOS file for the native simulation, a GOG copy runs the simulation under emulation (see The simulation file). GOG may also lag behind Steam with game updates; a version the app does not support will not start.

3. From a .zip archive

If you already have the Linux version of the game on a PC, pack its folder into a ZIP, copy it to the phone and add it with + on the main screen.

To download the Linux version on a PC, use the console of your own Steam client:

  1. Open steam://open/console in a browser.
  2. Run download_depot 457140 457143 (the Linux build) and, for the native simulation, download_depot 457140 457142 (the macOS build). Steam says where it saved them.
  3. ZIP the Linux build's folder, copy it to the phone and add it with +.

If the ZIP has no macOS SimDLL, the game still runs, with an emulated simulation. You can add the file at any time (see below). If the app says This copy is missing game files, the ZIP is not the complete current Linux version.

The simulation file (SimDLL)

Oxygen Not Included computes gases, liquids and temperature in a separate library, SimDLL, built for each platform. The Linux build has it for Intel/AMD processors only. The macOS build has it for ARM processors too, like a phone's, so OxyDroid runs that one natively.

  • With the macOS file (the Steam download brings it): the simulation is native.
  • Without it: the Linux file runs under emulation. The game starts and plays, but the simulation is slower, most of all in big colonies and at high speed. Before the launch the app says so: Start plays with emulation, Add file picks the macOS file.
  • Emulation also works the processor harder, so the phone heats up sooner. With a 60 FPS limit, a Galaxy S25 Ultra stays at 60, but after about 25 minutes of play the phone gets hot and the frame rate can drop to 35–48 for a while, until it cools down.

Instance settings → Additional files shows which one the instance uses and adds the macOS file later. It can be the file itself (OxygenNotIncluded.app/Contents/PlugIns/SimDLL.bundle/Contents/MacOS/SimDLL) or a ZIP of the macOS game, of OxygenNotIncluded.app or of SimDLL.bundle. It must be from the same game version as the Linux files.

DLC

The DLCs your Steam account owns (Spaced Out! and the packs) work in OxyDroid. The Steam download of the game brings them by itself. For an instance made otherwise:

  1. Bottom bar Game, tab DLC, sign in, Download my DLCs.
  2. The DLC content is saved as one ZIP in Download/OxyDroid (OxygenNotIncluded_DLC_…_build….zip).
  3. Add the downloaded DLC to an instance. Later, for a new instance, use Add DLC from a ZIP… with the same file.

The ZIP should be from the same game build as the instance: its name says the build.

Bottom bar Import → DLC: install a DLC ZIP into the chosen instance, or export the instance's DLCs into one, for another instance or another phone.

Mods

Oxygen Not Included loads mods with its own loader, as on a PC: mods with code (DLLs) work too. No Steam sign-in is needed for mods.

From the Steam Workshop

  1. Side menu → Steam Workshop: the game's Workshop, with Steam's own search.
  2. Add mods to the queue with the button on their cards, or on a mod's page.
  3. Download (N) opens the Mods tab of the Game page with the mods filled in. Tap Download mods: each one is saved as a ZIP in Download/OxyDroid.
  4. Install the downloaded mods into an instance.

You can also paste Workshop links or numbers into the Mods tab yourself.

From a ZIP

Bottom bar Mods → Install mods from a zip. One mod, several, or a copy of a PC's mods folder all work.

Switching on and the load order

  • New mods are switched on by themselves at the next game start. The game may restart once by itself so they load.
  • The Mods screen shows the game's own list in load order: switch mods on and off, move them up and down, delete them. Make changes while the game is not running.
  • Under each mod: the oldest game build it runs on, green when your game is that build or newer, red when the game is older; and the mod's version.
  • When you change mods inside the game, it restarts by itself.

Controls

On the bare screen

  • One finger uses the selected tool: a tap clicks, a drag is a left drag (dig, build, mop, every area tool).
  • Long press: right click.
  • Two fingers drag the map; a pinch zooms.

On-screen controls

  • Touchpad (bottom right): moves the mouse cursor like a laptop touchpad; a short tap on it clicks where the cursor is.
  • Floating stick (bottom left): moves the camera. Its whole zone, the faint area, takes the touch: put a finger anywhere in it and the stick appears under the finger. Touches in that zone do not reach the game.
  • Buttons: left and right click, Esc, pause, speed, zoom, the keyboard (KB), and one that hides the buttons.

Side menu → Edit on-screen controls changes the layout: position, size, opacity, the zone of a floating stick, touchpad sensitivity, and whether a touchpad shows its outline and label. Button icons puts a set of icons on the buttons.

Saves and Steam Cloud

Steam Cloud

Side menu → Steam Cloud saves, choose the instance and sign in.

  • From cloud: every colony of your account comes to the phone. A colony already on the phone is kept as a backup copy before it is replaced.
  • To cloud: choose colonies (each with the date of its last save). They go where the PC game finds them. A colony the cloud holds in another version is asked about once; nothing in the cloud is ever deleted. Close the game on the PC before sending.

Import and export

Bottom bar Import: saves, game settings, controls and mods of an instance, as ZIP files, out and back in.

Steam achievements

Achievements you earn are kept on the phone. Side menu → Steam achievements → Sync with Steam sends the new ones to your account and brings the account's back. The game does not need to run.

Picture and frame rate

  • Render resolution (instance settings): the game draws below the screen's resolution and the picture is scaled up. Lower means faster and cooler.
  • Frame rate: about 60 by default. Oxygen Not Included gains little above 60, and a higher rate keeps the phone working flat out.
  • Textures: the game's textures are made for PC graphics. On GPUs without those formats (Mali, PowerVR) they are converted once before the first launch of an instance; a progress window shows it. New instances also use the game's own low-resolution textures and a larger interface, made for a phone screen.
  • Vulkan compatibility: leave it on Auto. It is on for GPUs whose driver needs it.

Performance and heat

Oxygen Not Included is a heavy game: its simulation works on all cores. A phone that gets hot lowers its clocks by itself, and the frame rate drops with them.

  • Keep the frame rate at about 60 and lower the render resolution if the phone gets hot.
  • Close other apps: the game needs about 2–3 GB of memory.
  • On phones that support it, OxyDroid asks Android to keep the game on its fast cores (performance hints). On phones without that, the game's busiest threads are pinned to the big cores.
  • The native simulation (macOS SimDLL) is several times lighter than the emulated one.

For testers, in instance settings → environment variables:

  • OXYDROID_ADPF=0 turns the performance hints off.
  • OXYDROID_PIN_BIG=0 turns pinning off, =1 pins even with hints.
  • OXYDROID_SIMDLL=x86 runs the emulated simulation even with the macOS file.

Known issues

  • The on-screen keyboard types Latin letters only.
  • Pinch zoom is slow.
  • The game's intro videos are not shown.
  • Phones below the minimum, and Mali GPUs, are tested little so far: reports are welcome.
  • Android may close the game when it stays in the background for long.

Reporting a problem

Side menu → Report a bug packs the game's own log, the launcher's log and your phone's details into one ZIP, to send by email or to save as a file. Send it right after the problem: the logs keep only the last runs. A report also shows the frame rate, the busiest threads and the phone's temperature state minute by minute, so even a "it is slow" report says why.
